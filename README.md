# Sidharth Saini — Portfolio and assessment projects

## Portfolio
Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript. It includes About, Skills, Projects, Contact, project search, and a light/dark theme switch.

## Projects shown
The portfolio displays only the four GitHub repositories you supplied: Code with AI Quiz, Python Basic, Python Basics: Factorial, and Color Detection. Each card links to its repository.

## Chatbot
The current portfolio chatbot is still a placeholder. A working API chatbot requires a provider and a secret API key set privately in the Vercel project settings. Never place that secret in public HTML or JavaScript.

## Publish later
Create a GitHub repository for the portfolio, upload the portfolio files and project folders, then import the portfolio repository into Vercel. Add the chatbot backend and secret environment variable before claiming the chatbot is live.
